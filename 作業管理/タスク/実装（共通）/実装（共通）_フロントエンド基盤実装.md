# フロントエンド基盤実装

## スコープ

[要件定義書/画面一覧_v1.0.0.md](../../../要件定義書/画面一覧_v1.0.0.md)・[要件定義書/機能一覧_v1.0.0.md](../../../要件定義書/機能一覧_v1.0.0.md)に基づき、フロントエンド（React + TypeScript + Vite）の基盤（プロジェクト構成・ビルド設定・APIクライアント・認証状態管理・共通レイアウト）と、純粋に共通機能であるログイン（S01、F01）・パスワード変更（S06、F02）の2画面、および通知確認（F08）の共通ヘッダー部品を実装する。ホーム画面（S02）は、自分の貸出状況等（F13等）を含む他機能群バックログで追加するため、本タスクでは認証済みかどうかの確認に必要な最小限のプレースホルダーのみ実装する。

本機能には画面を伴うが、ユーザーからUI仕様書作成の明示的な依頼がないため、UI仕様書（HTML）は作成せず、要件定義書から直接実装する。
