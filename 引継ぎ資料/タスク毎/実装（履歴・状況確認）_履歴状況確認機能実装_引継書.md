    - `frontend/src/types/api.ts`：`MyLoanRequestListItemResponse`・`OverdueLoanRequestListItemResponse`・`LoanRequestHistoryListItemResponse`・`LoanRequestHistorySearchParams`の型を追加。
    - `frontend/src/api/client.ts`：CSV等の非JSON応答（ファイルダウンロード）を取得する`apiDownloadRequest`関数を新規追加（既存の`apiRequest`・`apiUploadRequest`と同様に401検知・エラーハンドリングを行う）。
    - `frontend/src/api/loanRequests.ts`：`getMyLoanRequests`・`getOverdueLoanRequests`・`getLoanRequestHistory`・`exportLoanRequestHistoryCsv`の4関数を追加。検索条件（開始日範囲・資産番号・申請者ID）は`URLSearchParams`でクエリ文字列化する共通処理（`buildLoanRequestHistoryQuery`）とした。
    - `frontend/src/pages/MyRequestsPage.tsx`（S05）：F07として、自分の申請・貸出状況一覧（申請ID・資産番号・備品名・開始日・返却予定日・用途・状態・却下・取消理由・申請日時）を表示するセクションを追加した。既存の申請取消処理成功後に一覧を再取得するようにした。
    - `frontend/src/pages/HomePage.tsx`（S02）：F13として、管理者のみに表示する期限超過件数セクションを追加した。件数が1件以上の場合、期限超過一覧画面へのリンクを表示する。
    - `frontend/src/pages/OverdueLoanRequestsPage.tsx`（S08、新規作成）：管理者向けの期限超過一覧画面。申請ID・資産番号・備品名・申請者・開始日・返却予定日・用途・貸出日時・超過日数を一覧表示する。
    - `frontend/src/pages/LoanRequestHistoryPage.tsx`（S11、新規作成）：管理者向けの貸出履歴画面。開始日範囲・資産番号・申請者IDで検索し、結果一覧（18列）を表示する。「CSV出力」ボタンから`exportLoanRequestHistoryCsv`でBlobを取得し、`URL.createObjectURL`＋一時的な`<a download>`要素でダウンロードさせる。
    - `frontend/src/App.tsx`・`frontend/src/components/Layout.tsx`：新規2画面（S08・S11）のルーティング（`AdminRoute`配下）・管理者向けナビゲーションリンクを追加した。
- disposable SQLite + FastAPI `TestClient`による機能テスト（約49件のアサーション）で、F07・F13・F17の正常系・異常系（認可境界、検索条件フィルタ、CSVのBOM・ヘッダー・日本語ラベル、CSVインジェクション対策のエスケープ）をすべて確認し、全件成功した。「貸出中かつ返却予定日超過」という通常のAPI操作列では再現不能な状態は、テストデータ準備としてDBの`due_date`列を直接操作して再現した（`実装（貸出・返却）`バックログと同様の手法）。
- Playwright（`frontend/node_modules`の既存パッケージを直接`require`する方式。disposableスクリプトで実施し確認後削除）で実際にChromiumを起動し、開発サーバー（バックエンド：disposable SQLite + `uvicorn`、フロントエンド：`npm run dev`）に対して管理者ログイン→初回パスワード変更→ホーム画面（F13期限超過件数セクション表示確認）→自分の申請一覧画面（F07一覧表示確認）→期限超過一覧画面（S08表示確認）→貸出履歴画面（S11、検索実行→CSV出力ボタンクリックによるダウンロード確認）の一連の操作を実施し、画面が設計どおりに動作しコンソールエラーが発生しないこと、CSVファイルがUTF-8 BOM付き・CRLF改行で正しくダウンロードされることを確認した。
