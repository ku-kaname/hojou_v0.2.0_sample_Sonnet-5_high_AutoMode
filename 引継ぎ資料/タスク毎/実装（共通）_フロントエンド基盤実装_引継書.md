## 目的・背景

フロントエンド（React + TypeScript + Vite）の基盤一式と、共通機能であるログイン・パスワード変更画面、通知表示の共通ヘッダー部品を実装する。本プロジェクトにはUI仕様書（HTML）が存在しないため（designスキル「UI仕様書作成はユーザーからの明示的な依頼があった場合のみ」に該当せず未作成）、要件定義書（画面一覧・機能一覧）から直接実装する。

- `src/types/api.ts`に、`backend/app/schemas.py`と一致する型（`LoginRequest`・`TokenResponse`・`PasswordChangeRequest`・`UserResponse`・`NotificationResponse`等）を定義した。
- `src/api/client.ts`に、Bearerトークン付与・JSON変換・401時の共通ハンドリング（`window`のCustomEvent `UNAUTHORIZED_EVENT`を発火し、React Router・contextと直接結合せずに全体へログアウトを伝播）を行う`apiRequest<T>()`を実装した。
- `src/api/auth.ts`（`login`・`logout`・`getMyInfo`・`changePassword`）・`src/api/notifications.ts`（`getNotifications`・`markNotificationRead`）を実装した。
- 認証状態管理を、react-refresh/only-export-componentsのLintルールに適合させるため3ファイルに分割して実装した：`src/context/AuthContext.ts`（型・Context定義のみ）・`src/context/AuthProvider.tsx`（Providerコンポーネント本体）・`src/context/useAuth.ts`（参照用hook）。
    - 当初は1ファイル（`AuthContext.tsx`）にまとめて実装しLint警告が出たため、削除のうえ上記3ファイルへ分割し、全import元（6箇所）を更新した。
- `src/components/ProtectedRoute.tsx`（未ログイン時はログイン画面へ、初回パスワード変更未完了時はパスワード変更画面へリダイレクト）・`src/components/Layout.tsx`（共通ヘッダー：通知表示・ログアウト）・`src/components/NotificationBell.tsx`（通知一覧の取得・表示・既読化）を実装した。
- `src/pages/LoginPage.tsx`（S01、F01）・`src/pages/PasswordChangePage.tsx`（S06、F02）・`src/pages/HomePage.tsx`（最小限のプレースホルダー。F13等は他バックログで追加）を実装した。
- `src/App.tsx`（ルーティング：`/login`は認証不要、それ以外は`ProtectedRoute`経由）・`src/main.tsx`・`src/index.css`を実装した。
- `frontend/Dockerfile`（マルチステージ：`node:20-slim`でビルド→`nginx:1.27-alpine`で配信）・`frontend/nginx.conf`（SPAフォールバック、`/api/`を`http://backend:8000/`へプロキシ）を実装した。
- `npm install`・`npm run build`（TypeScript＋Viteビルド）・`npm run lint`が全てエラー・警告0件で成功することを確認した。
- バックエンド（uvicorn）・フロントエンド（Vite dev server）を実際に起動し、Viteの開発用プロキシ経由で`POST /api/token`がバックエンドへ正しく転送され、有効なJWTが返ることを`curl`で確認した。
- Playwright（v1.64.1、Chromiumを追加インストール）でブラウザを実際に操作し、以下を確認した：
    - ログイン画面でadmin001／初期パスワードでログイン→パスワード変更画面へ自動遷移（`must_change_password`判定）
    - パスワード変更フォーム送信→ホーム画面へ遷移し、ユーザー名が表示される
    - 通知ベルのクリックで開閉トグルが動作する
    - ログアウト→ログイン画面へ遷移し、新パスワードで再ログインできる
    - 未ログイン状態で保護ルート（`/`）へ直接アクセスするとログイン画面へリダイレクトされる
    - 誤ったパスワードでログインするとエラーメッセージが表示される
    - この検証で、`NotificationBell`がパスワード変更前の画面（`PasswordChangePage`も`Layout`配下のため）でも通知取得を実行し、バックエンドの403（初回パスワード変更検証）がブラウザコンソールに未処理のエラーとして出ることを発見した。
- 上記の発見に対し、`src/components/NotificationBell.tsx`を修正し、`useAuth()`から取得した`user.must_change_password`が`true`の間は通知取得自体を行わないようにした（`useEffect`の依存配列に`user`を追加し、`must_change_password`時は早期return）。修正後、`npm run build`・`npm run lint`が成功し、Playwrightの再実行でコンソールエラーが解消されたことを確認した。
