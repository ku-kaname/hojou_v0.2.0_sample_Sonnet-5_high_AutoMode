### 処理概要

#### 【目的】
- 環境変数で指定された初期管理者アカウントを、システム構築時に起動時処理として自動作成する（機能要件「管理者ユーザーの作成・管理」参照）。

#### 【処理概略】
- 環境変数で指定されたユーザーIDが未登録の場合のみ、管理者ロールのユーザーを新規作成する。
- 既に同一ユーザーIDが登録済みの場合は何も行わない（再起動時の冪等性を保つ）。

## ○処理詳細

### 1. 環境変数読み込み

- (1) `ADMIN_USER_ID`／`ADMIN_NAME`／`ADMIN_PASSWORD`を読み込む。
- (2) いずれかが未設定の場合、例外処理（上記バリデーションエラー参照）。

### 2. 既存ユーザー確認

- (1) USERテーブルから取得する。

  ```sql
  SELECT
    id                 -- ユーザー情報．内部ID
  FROM user
  WHERE
    user_id = :admin_user_id;  -- 環境変数．初期管理者ユーザーID
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 取得内容 | 内部ID | - | - | 存在確認のみに使用 |
  | 検索条件 | ユーザーID | ○ | 環境変数．初期管理者ユーザーID | - |

- (2) 取得できた場合（既に初期管理者アカウントが作成済み）、以降の処理を行わず終了する。

### 3. パスワードハッシュ化

- (1) 環境変数．初期管理者初期パスワードをArgon2idでハッシュ化する

### 4. 管理者ユーザーレコード新規作成

- (1) USERテーブルに新規レコードを追加する。

  ```sql
  INSERT INTO user (
    user_id,                 -- ユーザー情報．ユーザーID
    name,                    -- ユーザー情報．氏名
    department,              -- ユーザー情報．所属
    hashed_password,         -- ユーザー情報．パスワードハッシュ
    role,                    -- ユーザー情報．ロール
    is_active,               -- ユーザー情報．有効フラグ
    must_change_password,    -- ユーザー情報．初回パスワード変更要否フラグ
    failed_login_count,      -- ユーザー情報．連続ログイン失敗回数
    locked_until,            -- ユーザー情報．ロック解除日時
    token_version,           -- ユーザー情報．トークン世代
    created_at               -- ユーザー情報．作成日時
  ) VALUES (
    :user_id, :name, :department, :hashed_password, :role,
    :is_active, :must_change_password, :failed_login_count, :locked_until, :token_version, :created_at
  );
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 登録内容 | ユーザーID | ○ | 環境変数．初期管理者ユーザーID | - |
  | 登録内容 | 氏名 | ○ | 環境変数．初期管理者氏名 | - |
  | 登録内容 | 所属 | - | `null` | - |
  | 登録内容 | パスワードハッシュ | ○ | パスワードハッシュ化．エンコード結果 | - |
  | 登録内容 | ロール | ○ | `admin` | - |
  | 登録内容 | 有効フラグ | ○ | `true` | - |
  | 登録内容 | 初回パスワード変更要否フラグ | ○ | `true` | 環境変数経由で設定された初期パスワードも、管理者が設定する初期パスワードと同様に扱い、初回ログイン時の変更を必須とする（機能要件「ユーザー登録時・パスワード初期化時に管理者が設定した初期パスワードは、初回ログイン時に変更を必須とする」と同一の解釈を適用。要件定義書はこのアカウントを明示的に対象外としていないため、設計工程での判断として本書に明記する） |
  | 登録内容 | 連続ログイン失敗回数 | ○ | `0` | - |
  | 登録内容 | ロック解除日時 | - | `null` | - |
  | 登録内容 | トークン世代 | ○ | `0` | - |
  | 登録内容 | 作成日時 | ○ | 現在時刻 | - |
