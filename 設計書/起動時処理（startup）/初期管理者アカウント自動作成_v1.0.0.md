### メソッド名

| 項目 | 内容 |
|---|---|
| メソッド論理名 | 初期管理者アカウント自動作成 |
| メソッド物理名 | create_initial_admin_on_startup |

### 処理概要

#### 【目的】
- 環境変数で指定された初期管理者アカウントを、システム構築時に起動時処理として自動作成する（機能要件「管理者ユーザーの作成・管理」参照）。

#### 【処理概略】
- 環境変数で指定されたユーザーIDが未登録の場合のみ、管理者ロールのユーザーを新規作成する。
- 既に同一ユーザーIDが登録済みの場合は何も行わない（再起動時の冪等性を保つ）。

## ○処理詳細

### 1. 環境変数読み込み

- (1) `ADMIN_USER_ID`／`ADMIN_NAME`／`ADMIN_PASSWORD`を読み込む。
- (2) いずれかが未設定の場合、例外処理（上記バリデーションエラー参照）。

### 2. 既存ユーザー確認

- (1) 以下メソッドを呼び出す。

  **呼出先**

  | 項目 | 論理名 | 物理名 |
  |---|---|---|
  | クラス | - | - |
  | メソッド | ユーザー取得（ユーザーID指定） | get_user_by_user_id |

  **引数**

  | 引数 | 型 | 必須 | 設定値 | 備考 |
  |---|---|:---:|---|---|
  | データベース | `Session` | ○ | 入力値．データベース | - |
  | ユーザーID | `str` | ○ | 環境変数．初期管理者ユーザーID | - |

- (2) 取得できた場合（既に初期管理者アカウントが作成済み）、以降の処理を行わず終了する。

### 3. パスワードハッシュ化

- (1) 環境変数．初期管理者初期パスワードをArgon2idでハッシュ化する

### 4. 管理者ユーザーレコード新規作成

- (1) 以下メソッドを呼び出す。

  **呼出先**

  | 項目 | 論理名 | 物理名 |
  |---|---|---|
  | クラス | - | - |
  | メソッド | ユーザー登録 | create_user |

  **引数**

  | 引数 | 型 | 必須 | 設定値 | 備考 |
  |---|---|:---:|---|---|
  | データベース | `Session` | ○ | 入力値．データベース | - |
  | ユーザーID | `str` | ○ | 環境変数．初期管理者ユーザーID | - |
  | 氏名 | `str` | ○ | 環境変数．初期管理者氏名 | - |
  | 所属 | `str \| None` | - | `null` | - |
  | パスワードハッシュ | `str` | ○ | パスワードハッシュ化．エンコード結果 | - |
  | ロール | `str` | ○ | `admin` | - |

  ※「ユーザー登録」呼出先の内部仕様により、初回パスワード変更要否フラグは常に`true`で登録される。環境変数経由で設定された初期パスワードも、管理者が設定する初期パスワードと同様に扱い、初回ログイン時の変更を必須とする（機能要件「ユーザー登録時・パスワード初期化時に管理者が設定した初期パスワードは、初回ログイン時に変更を必須とする」と同一の解釈を適用。要件定義書はこのアカウントを明示的に対象外としていないため、設計工程での判断として本書に明記する）。
