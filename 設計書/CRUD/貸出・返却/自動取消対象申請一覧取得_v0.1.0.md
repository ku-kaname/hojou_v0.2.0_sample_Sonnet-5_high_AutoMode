### 処理概要

#### 【目的】
- ノーショー（貸出処理・承認却下の未実施放置）により自動取消の対象となる申請を一覧取得する。

#### 【処理概略】
- 「承認済みで返却予定日を過ぎている」または「申請中で開始日を過ぎている」申請をLOAN_REQUESTテーブルから取得する。
- ノーショー自動取消（日次バッチ）から呼び出される。

## ○処理詳細

### 1. 自動取消対象申請一覧取得

- (1) LOAN_REQUESTテーブルから取得する。

  ```sql
  SELECT
    id,                 -- 貸出申請情報．内部ID
    applicant_user_id   -- 貸出申請情報．申請者ユーザーID
  FROM loan_request
  WHERE
    (status = 'approved' AND due_date < :today)    -- 貸出申請情報．状態、返却予定日
    OR (status = 'pending' AND start_date < :today); -- 貸出申請情報．状態、開始日
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 取得内容 | 内部ID | - | - | - |
  | 取得内容 | 申請者ユーザーID | - | - | - |
  | 検索条件 | 状態 | ○ | `approved` または `pending` | - |
  | 検索条件 | 返却予定日 | - | 入力値．今日（`approved`の場合のみ比較） | - |
  | 検索条件 | 開始日 | - | 入力値．今日（`pending`の場合のみ比較） | - |
