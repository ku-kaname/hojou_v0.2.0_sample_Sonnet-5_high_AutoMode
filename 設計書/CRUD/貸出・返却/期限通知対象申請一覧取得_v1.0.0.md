### 処理概要

#### 【目的】
- 返却期限の通知対象となる、貸出中の申請を一覧取得する。

#### 【処理概略】
- 「貸出中で返却予定日が明日」または「貸出中で返却予定日を過ぎている（期限超過中）」申請をLOAN_REQUESTテーブルから取得する。
- 期限通知生成（日次バッチ）から呼び出される。

## ○処理詳細

### 1. 期限通知対象申請一覧取得

- (1) LOAN_REQUESTテーブルから取得する。

  ```sql
  SELECT
    id,                 -- 貸出申請情報．内部ID
    applicant_user_id   -- 貸出申請情報．申請者ユーザーID
  FROM loan_request
  WHERE
    status = 'lending'                              -- 貸出申請情報．状態
    AND (due_date = :tomorrow OR due_date < :today);  -- 貸出申請情報．返却予定日
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 取得内容 | 内部ID | - | - | - |
  | 取得内容 | 申請者ユーザーID | - | - | - |
  | 検索条件 | 状態 | ○ | `lending` | - |
  | 検索条件 | 返却予定日 | ○ | 入力値．明日（前日通知）または入力値．今日より前（期限超過中） | - |
