### 処理概要

#### 【目的】
- ノーショーにより貸出申請を自動取消する。

#### 【処理概略】
- 入力値の内部IDに一致する申請の状態を「取消」に更新する。取消した者ユーザーIDは設定しない（自動取消のため）。
- 既存の申請取消（`cancel_loan_request`）は取消した者ユーザーIDを必須としているため、自動取消専用に本メソッドを新規作成する。

## ○処理詳細

### 1. 自動取消

- (1) LOAN_REQUESTテーブルを更新する。

  ```sql
  UPDATE loan_request
  SET
    status = 'cancelled',    -- 貸出申請情報．状態
    cancelled_at = :cancelled_at  -- 貸出申請情報．取消日時
  WHERE
    id = :loan_request_internal_id;  -- 入力値．内部ID
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 更新内容 | 状態 | ○ | `cancelled` | - |
  | 更新内容 | 取消日時 | ○ | 現在時刻 | - |
  | 検索条件 | 内部ID | ○ | 入力値．内部ID | - |

  - ① 取消した者ユーザーID・却下・取消理由は更新しない（自動取消は空のまま。テーブル定義書「取消した者ユーザーID」備考参照）。
