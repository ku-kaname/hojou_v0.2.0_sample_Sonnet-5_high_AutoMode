| メソッド論理名 | 備品取得（内部ID指定） |
| メソッド物理名 | get_equipment_by_id |

### 処理概要

#### 【目的】
- 指定した内部IDの備品を1件取得する。

#### 【処理概略】
- 入力値の内部IDに一致する備品をEQUIPMENTテーブルから取得する。該当がない場合は`None`を返す。
- 貸出処理（F10）から、対象備品の有効フラグ確認のために呼び出される。

## ○処理詳細

### 1. 備品取得

- (1) EQUIPMENTテーブルから取得する。

  ```sql
  SELECT
    *  -- 備品情報
  FROM equipment
  WHERE
    id = :equipment_internal_id;  -- 入力値．内部ID
  ```
