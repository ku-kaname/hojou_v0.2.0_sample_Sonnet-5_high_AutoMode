## ○処理詳細

### 1. 貸出処理

- (1) LOAN_REQUESTテーブルを更新する。

  ```sql
  UPDATE loan_request
  SET
    status = 'lending',              -- 貸出申請情報．状態
    lent_by_user_id = :lent_by_user_id,  -- 貸出申請情報．貸出処理した管理者ユーザーID
    lent_at = :lent_at                 -- 貸出申請情報．貸出日時
  WHERE
    id = :loan_request_internal_id;    -- 入力値．内部ID
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 更新内容 | 状態 | ○ | `lending` | - |
  | 更新内容 | 貸出処理した管理者ユーザーID | ○ | 入力値．貸出処理した管理者ユーザー内部ID | - |
  | 更新内容 | 貸出日時 | ○ | 現在時刻 | - |
  | 検索条件 | 内部ID | ○ | 入力値．内部ID | - |
