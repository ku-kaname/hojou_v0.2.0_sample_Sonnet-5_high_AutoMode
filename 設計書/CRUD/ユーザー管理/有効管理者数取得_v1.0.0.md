## ○処理詳細

### 1. 有効管理者数取得

- (1) USERテーブルから取得する。

  ```sql
  SELECT
    COUNT(*)  -- ユーザー情報．件数
  FROM user
  WHERE
    role = 'admin'        -- ユーザー情報．ロール
    AND is_active = true;  -- ユーザー情報．有効フラグ
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 取得内容 | 件数 | ○ | - | - |
  | 検索条件 | ロール | ○ | `admin` | - |
  | 検索条件 | 有効フラグ | ○ | `true` | - |
