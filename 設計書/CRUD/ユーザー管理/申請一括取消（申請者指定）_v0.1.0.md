### 処理概要

#### 【目的】
- 指定した申請者の、申請中・承認済みの申請を自動的に取消する。

#### 【処理概略】
- 入力値の申請者ユーザーIDに一致し、状態が申請中または承認済みである申請を、LOAN_REQUESTテーブルで取消状態に更新する。

## ○処理詳細

### 1. 申請一括取消

- (1) LOAN_REQUESTテーブルを更新する。

  ```sql
  UPDATE loan_request
  SET
    status = 'cancelled',                            -- 貸出申請情報．状態
    rejection_reason = 'ユーザー無効化による自動取消',   -- 貸出申請情報．却下・取消理由
    cancelled_at = :cancelled_at                      -- 貸出申請情報．取消日時
  WHERE
    applicant_user_id = :applicant_user_id   -- 入力値．申請者ユーザーID
    AND status IN ('pending', 'approved');   -- 貸出申請情報．状態
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 更新内容 | 状態 | ○ | `cancelled` | - |
  | 更新内容 | 却下・取消理由 | ○ | "ユーザー無効化による自動取消" | - |
  | 更新内容 | 取消日時 | ○ | 現在時刻 | - |
  | 検索条件 | 申請者ユーザーID | ○ | 入力値．申請者ユーザーID | - |
  | 検索条件 | 状態 | ○ | `pending`／`approved` | - |

  ※取消した者ユーザーID（`cancelled_by_user_id`）は、自動取消のため設定しない（空のまま）。
