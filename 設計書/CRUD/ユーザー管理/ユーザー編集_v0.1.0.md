## ○処理詳細

### 1. ユーザー編集

- (1) USERテーブルを更新する。

  ```sql
  UPDATE user
  SET
    name = :name,                      -- ユーザー情報．氏名
    department = :department,          -- ユーザー情報．所属
    role = :role,                      -- ユーザー情報．ロール
    token_version = :token_version,    -- ユーザー情報．トークン世代
    updated_at = :updated_at           -- ユーザー情報．更新日時
  WHERE
    id = :user_internal_id;  -- 入力値．内部ID
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 更新内容 | 氏名 | ○ | 入力値．氏名 | - |
  | 更新内容 | 所属 | - | 入力値．所属 | - |
  | 更新内容 | ロール | ○ | 入力値．ロール | - |
  | 更新内容 | トークン世代 | ○ | 入力値．トークン世代 | - |
  | 更新内容 | 更新日時 | ○ | 現在時刻 | - |
  | 検索条件 | 内部ID | ○ | 入力値．内部ID | - |
