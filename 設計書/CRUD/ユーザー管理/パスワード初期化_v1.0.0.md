### 処理概要

#### 【目的】
- ユーザーのパスワードを初期化する。

#### 【処理概略】
- 入力値の内部IDに一致するユーザー情報のパスワードハッシュを更新し、初回パスワード変更要否フラグを`true`に設定し、トークン世代を更新する。

## ○処理詳細

### 1. パスワード初期化

- (1) USERテーブルを更新する。

  ```sql
  UPDATE user
  SET
    hashed_password = :hashed_password,      -- ユーザー情報．パスワードハッシュ
    must_change_password = true,             -- ユーザー情報．初回パスワード変更要否フラグ
    token_version = :token_version,          -- ユーザー情報．トークン世代
    updated_at = :updated_at                 -- ユーザー情報．更新日時
  WHERE
    id = :user_internal_id;  -- 入力値．内部ID
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 更新内容 | パスワードハッシュ | ○ | 入力値．パスワードハッシュ | - |
  | 更新内容 | 初回パスワード変更要否フラグ | ○ | `true` | - |
  | 更新内容 | トークン世代 | ○ | 入力値．トークン世代 | - |
  | 更新内容 | 更新日時 | ○ | 現在時刻 | - |
  | 検索条件 | 内部ID | ○ | 入力値．内部ID | - |
