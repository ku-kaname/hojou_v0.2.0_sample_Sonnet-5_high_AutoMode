## ○処理詳細

### 1. ユーザー一覧を取得する

- (1) USERテーブルから取得する。

  ```sql
  SELECT
    id,                    -- ユーザー情報．内部ID
    user_id,                -- ユーザー情報．ユーザーID
    name,                   -- ユーザー情報．氏名
    department,             -- ユーザー情報．所属
    role,                   -- ユーザー情報．ロール
    is_active,              -- ユーザー情報．有効フラグ
    must_change_password,   -- ユーザー情報．初回パスワード変更要否フラグ
    created_at,              -- ユーザー情報．作成日時
    updated_at               -- ユーザー情報．更新日時
  FROM user
  ORDER BY
    user_id ASC;  -- ユーザー情報．ユーザーID
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 取得内容 | 内部ID | - | - | - |
  | 取得内容 | ユーザーID | - | - | - |
  | 取得内容 | 氏名 | - | - | - |
  | 取得内容 | 所属 | - | - | - |
  | 取得内容 | ロール | - | - | - |
  | 取得内容 | 有効フラグ | - | - | - |
  | 取得内容 | 初回パスワード変更要否フラグ | - | - | - |
  | 取得内容 | 作成日時 | - | - | - |
  | 取得内容 | 更新日時 | - | - | - |
