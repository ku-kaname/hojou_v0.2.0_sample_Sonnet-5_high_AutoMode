### 処理概要

#### 【目的】

#### 【処理概略】
- 備品内部ID・申請者ユーザー内部ID・開始日・返却予定日・用途を設定した申請レコードを新規作成し、DBに追加する。状態は「申請中」で初期化する。

## ○処理詳細

### 1. 貸出申請レコードを新規作成してDBに追加

- (1) LOAN_REQUESTテーブルに新規レコードを追加する。

  ```sql
  INSERT INTO loan_request (
    equipment_id,         -- 貸出申請情報．備品ID
    applicant_user_id,     -- 貸出申請情報．申請者ユーザーID
    start_date,             -- 貸出申請情報．開始日
    due_date,                -- 貸出申請情報．返却予定日
    purpose,                  -- 貸出申請情報．用途
    status,                    -- 貸出申請情報．状態
    requested_at                -- 貸出申請情報．申請日時
  ) VALUES (
    :equipment_internal_id, :applicant_user_id, :start_date, :due_date, :purpose, :status, :requested_at
  );
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 登録内容 | 備品ID | ○ | 入力値．備品内部ID | - |
  | 登録内容 | 申請者ユーザーID | ○ | 入力値．申請者ユーザー内部ID | - |
  | 登録内容 | 開始日 | ○ | 入力値．開始日 | - |
  | 登録内容 | 返却予定日 | ○ | 入力値．返却予定日 | - |
  | 登録内容 | 用途 | ○ | 入力値．用途 | - |
  | 登録内容 | 状態 | ○ | `pending` | - |
  | 登録内容 | 申請日時 | ○ | 現在時刻 | - |
