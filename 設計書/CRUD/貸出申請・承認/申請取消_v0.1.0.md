| メソッド物理名 | cancel_loan_request |

### 処理概要

#### 【目的】
- 貸出申請を取消する。

#### 【処理概略】
- 入力値の内部IDに一致する申請の状態を「取消」に更新する。
- 申請者本人による取消（F06）・管理者による取消（F12）の双方から呼び出される。取消理由は、管理者取消時は入力値を設定し、申請者本人取消時は`None`を設定する。

## ○処理詳細

### 1. 申請取消

- (1) LOAN_REQUESTテーブルを更新する。

  ```sql
  UPDATE loan_request
  SET
    status = 'cancelled',             -- 貸出申請情報．状態
    rejection_reason = :cancellation_reason,  -- 貸出申請情報．却下・取消理由
    cancelled_by_user_id = :cancelled_by_user_id,  -- 貸出申請情報．取消した者ユーザーID
    cancelled_at = :cancelled_at        -- 貸出申請情報．取消日時
  WHERE
    id = :loan_request_internal_id;      -- 入力値．内部ID
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 更新内容 | 状態 | ○ | `cancelled` | - |
  | 更新内容 | 却下・取消理由 | - | 入力値．取消理由 | - |
  | 更新内容 | 取消した者ユーザーID | ○ | 入力値．取消した者ユーザー内部ID | - |
  | 更新内容 | 取消日時 | ○ | 現在時刻 | - |
  | 検索条件 | 内部ID | ○ | 入力値．内部ID | - |
