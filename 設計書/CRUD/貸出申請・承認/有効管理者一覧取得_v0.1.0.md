## ○処理詳細

### 1. 有効管理者一覧を取得

- (1) USERテーブルから取得する。

  ```sql
  SELECT
    *  -- ユーザー情報
  FROM user
  WHERE
    role = 'admin'          -- ユーザー情報．権限
    AND is_active = true;     -- ユーザー情報．有効状態
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 取得内容 | ユーザー情報 | - | - | - |
  | 検索条件 | 権限 | ○ | `admin` | - |
  | 検索条件 | 有効状態 | ○ | `true` | - |
