## ○処理詳細

### 1. 申請承認

- (1) LOAN_REQUESTテーブルを更新する。

  ```sql
  UPDATE loan_request
  SET
    status = 'approved',                   -- 貸出申請情報．状態
    approved_by_user_id = :approved_by_user_id,  -- 貸出申請情報．承認・却下した管理者ユーザーID
    decided_at = :decided_at                 -- 貸出申請情報．承認・却下日時
  WHERE
    id = :loan_request_internal_id;            -- 入力値．内部ID
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 更新内容 | 状態 | ○ | `approved` | - |
  | 更新内容 | 承認・却下した管理者ユーザーID | ○ | 入力値．承認した管理者ユーザー内部ID | - |
  | 更新内容 | 承認・却下日時 | ○ | 現在時刻 | - |
  | 検索条件 | 内部ID | ○ | 入力値．内部ID | - |
