## ○処理詳細

### 1. 貸出申請の詳細を取得

- (1) LOAN_REQUESTテーブルを、EQUIPMENTテーブル・USERテーブルと結合して取得する。

  ```sql
  SELECT
    loan_request.*,       -- 貸出申請情報
    equipment.asset_number, -- 備品情報．資産番号
    equipment.name,         -- 備品情報．備品名
    user.name AS applicant_name  -- ユーザー情報．氏名（申請者）
  FROM loan_request
  INNER JOIN equipment ON loan_request.equipment_id = equipment.id
  INNER JOIN user ON loan_request.applicant_user_id = user.id
  WHERE
    loan_request.id = :loan_request_internal_id;  -- 入力値．内部ID
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 取得内容 | 貸出申請情報 | - | - | - |
  | 取得内容 | 備品情報．資産番号 | - | - | - |
  | 取得内容 | 備品情報．備品名 | - | - | - |
  | 取得内容 | ユーザー情報．氏名（申請者） | - | - | - |
  | 結合条件 | 備品ID | ○ | 貸出申請情報．備品ID = 備品情報．内部ID | - |
  | 結合条件 | 申請者ユーザーID | ○ | 貸出申請情報．申請者ユーザーID = ユーザー情報．内部ID | - |
  | 検索条件 | 内部ID | ○ | 入力値．内部ID | - |
