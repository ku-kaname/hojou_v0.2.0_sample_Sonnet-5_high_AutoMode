### 処理概要

#### 【目的】
- 指定した申請者ユーザーが行った貸出申請を、申請日時の降順で一覧取得する。

#### 【処理概略】
- LOAN_REQUESTテーブルを、EQUIPMENTテーブルと結合し、申請者ユーザー内部IDが一致するレコードを申請日時の降順で取得する。

## ○処理詳細

### 1. 自分申請一覧を取得

- (1) LOAN_REQUESTテーブルを、EQUIPMENTテーブルと結合して取得する。

  ```sql
  SELECT
    loan_request.*,         -- 貸出申請情報
    equipment.asset_number, -- 備品情報．資産番号
    equipment.name           -- 備品情報．備品名
  FROM loan_request
  INNER JOIN equipment ON loan_request.equipment_id = equipment.id
  WHERE
    loan_request.applicant_user_id = :applicant_user_id  -- 検索条件．申請者ユーザー内部ID
  ORDER BY
    loan_request.requested_at DESC;  -- 貸出申請情報．申請日時
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 取得内容 | 貸出申請情報 | - | - | - |
  | 取得内容 | 備品情報．資産番号 | - | - | - |
  | 取得内容 | 備品情報．備品名 | - | - | - |
  | 結合条件 | 備品ID | ○ | 貸出申請情報．備品ID = 備品情報．内部ID | - |
  | 検索条件 | 申請者ユーザー内部ID | ○ | 入力値．申請者ユーザー内部ID | - |
  | 並び順 | 申請日時 | ○ | 降順 | - |
