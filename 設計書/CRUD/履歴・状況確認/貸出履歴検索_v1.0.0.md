### 処理概要

#### 【目的】
- 検索条件（期間・備品・借用者）に応じて、全ユーザーの貸出申請を履歴として一覧取得する。

#### 【処理概略】
- 開始日の範囲・資産番号・借用者ユーザーIDの検索条件に一致する貸出申請を、EQUIPMENTテーブル・USERテーブル（申請者・承認者・貸出処理者・返却処理者・取消処理者）と結合し、開始日の降順でLOAN_REQUESTテーブルから取得する。

## ○処理詳細

### 1. 貸出履歴一覧を取得

- (1) LOAN_REQUESTテーブルを、EQUIPMENTテーブル・USERテーブル（申請者・承認者・貸出処理者・返却処理者・取消処理者）と結合して取得する。

  ```sql
  SELECT
    loan_request.*,                       -- 貸出申請情報
    equipment.asset_number,               -- 備品情報．資産番号
    equipment.name,                         -- 備品情報．備品名
    applicant_user.name AS applicant_name,  -- ユーザー情報．氏名（申請者）
    approved_by_user.name AS approved_by_name,  -- ユーザー情報．氏名（承認・却下者）
    lent_by_user.name AS lent_by_name,          -- ユーザー情報．氏名（貸出処理者）
    returned_by_user.name AS returned_by_name,  -- ユーザー情報．氏名（返却処理者）
    cancelled_by_user.name AS cancelled_by_name -- ユーザー情報．氏名（取消処理者）
  FROM loan_request
  INNER JOIN equipment
    ON loan_request.equipment_id = equipment.id
  INNER JOIN user AS applicant_user
    ON loan_request.applicant_user_id = applicant_user.id
  LEFT JOIN user AS approved_by_user
    ON loan_request.approved_by_user_id = approved_by_user.id
  LEFT JOIN user AS lent_by_user
    ON loan_request.lent_by_user_id = lent_by_user.id
  LEFT JOIN user AS returned_by_user
    ON loan_request.returned_by_user_id = returned_by_user.id
  LEFT JOIN user AS cancelled_by_user
    ON loan_request.cancelled_by_user_id = cancelled_by_user.id
  WHERE
    (:start_date_from IS NULL OR loan_request.start_date >= :start_date_from)  -- 検索条件．開始日（自）
    AND (:start_date_to IS NULL OR loan_request.start_date <= :start_date_to)    -- 検索条件．開始日（至）
    AND (:asset_number IS NULL OR equipment.asset_number = :asset_number)       -- 検索条件．資産番号
    AND (:user_id IS NULL OR applicant_user.user_id = :user_id)                 -- 検索条件．借用者ユーザーID
  ORDER BY
    loan_request.start_date DESC;  -- 貸出申請情報．開始日
  ```
