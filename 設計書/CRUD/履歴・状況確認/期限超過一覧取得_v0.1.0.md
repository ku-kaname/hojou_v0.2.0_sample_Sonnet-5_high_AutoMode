### 処理概要

#### 【目的】
- 返却予定日を過ぎた「貸出中」の申請を一覧取得し、各申請の期限超過日数を算出する。

#### 【処理概略】
- LOAN_REQUESTテーブルを、EQUIPMENTテーブル・USERテーブルと結合し、状態が「貸出中」かつ返却予定日が指定日より前のレコードを、返却予定日の昇順で取得する。
- 取得した各レコードについて、指定日と返却予定日の差分から期限超過日数を算出する。

## ○処理詳細

### 1. 期限超過申請一覧を取得

- (1) LOAN_REQUESTテーブルを、EQUIPMENTテーブル・USERテーブルと結合して取得する。

  ```sql
  SELECT
    loan_request.*,              -- 貸出申請情報
    equipment.asset_number,      -- 備品情報．資産番号
    equipment.name,                -- 備品情報．備品名
    user.name AS applicant_name  -- ユーザー情報．氏名（申請者）
  FROM loan_request
  INNER JOIN equipment ON loan_request.equipment_id = equipment.id
  INNER JOIN user ON loan_request.applicant_user_id = user.id
  WHERE
    loan_request.status = 'lending'            -- 検索条件．貸出申請情報．状態
    AND loan_request.due_date < :today           -- 検索条件．基準日
  ORDER BY
    loan_request.due_date ASC;  -- 貸出申請情報．返却予定日
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 取得内容 | 貸出申請情報 | - | - | - |
  | 取得内容 | 備品情報．資産番号 | - | - | - |
  | 取得内容 | 備品情報．備品名 | - | - | - |
  | 取得内容 | ユーザー情報．氏名（申請者） | - | - | - |
  | 結合条件 | 備品ID | ○ | 貸出申請情報．備品ID = 備品情報．内部ID | - |
  | 結合条件 | 申請者ユーザーID | ○ | 貸出申請情報．申請者ユーザーID = ユーザー情報．内部ID | - |
  | 検索条件 | 状態 | ○ | `lending` | - |
  | 検索条件 | 返却予定日 | ○ | 入力値．基準日より前 | - |
  | 並び順 | 返却予定日 | ○ | 昇順 | 最も期限超過が長い申請を先頭にする |

- (2) 取得結果の各行について、期限超過日数を算出する

  - ① 期限超過日数 ＝ 入力値．基準日 － 取得結果．返却予定日（日数）
