### 処理概要

#### 【目的】
- 指定した備品について、状態が「承認済み」「貸出中」である申請の期間を一覧取得する。

#### 【処理概略】
- 入力値の備品内部IDに一致し、状態が「承認済み」「貸出中」である申請を、申請者情報と内部結合して、開始日の昇順でLOAN_REQUESTテーブルから取得する。

## ○処理詳細

### 1. 予約期間一覧取得

- (1) LOAN_REQUESTテーブルとUSERテーブルを内部結合して取得する。

  ```sql
  SELECT
    lr.start_date,    -- 貸出申請情報．開始日
    lr.due_date,       -- 貸出申請情報．返却予定日
    lr.status,          -- 貸出申請情報．状態
    u.name               -- ユーザー情報．氏名（申請者）
  FROM loan_request lr
  JOIN user u
    ON u.id = lr.applicant_user_id
  WHERE
    lr.equipment_id = :equipment_internal_id          -- 入力値．備品内部ID
    AND lr.status IN ('approved', 'lending')            -- 検索条件．貸出申請情報．状態
  ORDER BY
    lr.start_date ASC;
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 取得内容 | 開始日 | - | - | - |
  | 取得内容 | 返却予定日 | - | - | - |
  | 取得内容 | 状態 | - | - | - |
  | 取得内容 | 氏名（申請者） | - | - | - |
  | 検索条件 | 備品内部ID | ○ | 入力値．備品内部ID | - |
  | 検索条件 | 状態 | ○ | `approved`, `lending` | - |
