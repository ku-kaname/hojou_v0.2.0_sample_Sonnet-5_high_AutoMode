## ○処理詳細

### 1. 備品編集

- (1) EQUIPMENTテーブルを更新する。

  ```sql
  UPDATE equipment
  SET
    name = :name,                -- 備品情報．備品名
    category = :category,        -- 備品情報．分類
    description = :description,  -- 備品情報．説明
    location = :location,        -- 備品情報．保管場所
    updated_at = :updated_at     -- 備品情報．更新日時
  WHERE
    id = :equipment_internal_id;  -- 入力値．内部ID
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 更新内容 | 備品名 | ○ | 入力値．備品名 | - |
  | 更新内容 | 分類 | ○ | 入力値．分類 | - |
  | 更新内容 | 説明 | - | 入力値．説明 | - |
  | 更新内容 | 保管場所 | - | 入力値．保管場所 | - |
  | 更新内容 | 更新日時 | ○ | 現在時刻 | - |
  | 検索条件 | 内部ID | ○ | 入力値．内部ID | - |
