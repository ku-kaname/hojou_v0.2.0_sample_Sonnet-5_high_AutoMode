### 処理概要

#### 【目的】
- 無効化された備品を再有効化する。

#### 【処理概略】
- 入力値の内部IDに一致する備品情報の有効フラグを`true`に更新する。

## ○処理詳細

### 1. 備品再有効化

- (1) EQUIPMENTテーブルを更新する。

  ```sql
  UPDATE equipment
  SET
    is_active = true,          -- 備品情報．有効フラグ
    updated_at = :updated_at   -- 備品情報．更新日時
  WHERE
    id = :equipment_internal_id;  -- 入力値．内部ID
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 更新内容 | 有効フラグ | ○ | `true` | - |
  | 更新内容 | 更新日時 | ○ | 現在時刻 | - |
  | 検索条件 | 内部ID | ○ | 入力値．内部ID | - |
