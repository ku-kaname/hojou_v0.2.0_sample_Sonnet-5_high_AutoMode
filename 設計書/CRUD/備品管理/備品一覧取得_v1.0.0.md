### 処理概要

#### 【目的】
- 検索条件に応じて備品を一覧取得する。現在の貸出状況を合わせて取得する。

#### 【処理概略】
- 分類・キーワード・有効フラグの検索条件に一致する備品情報を、資産番号の昇順でEQUIPMENTテーブルから取得する。
- 各備品について、状態が「貸出中」の申請をLOAN_REQUESTテーブルから左外部結合で取得し、貸出状況・返却予定日を判定する。

## ○処理詳細

### 1. 備品一覧取得

- (1) EQUIPMENTテーブルと、状態が「貸出中」の申請をLOAN_REQUESTテーブルから左外部結合して取得する。

  ```sql
  SELECT
    e.id,              -- 備品情報．内部ID
    e.asset_number,    -- 備品情報．資産番号
    e.name,            -- 備品情報．備品名
    e.category,        -- 備品情報．分類
    e.description,     -- 備品情報．説明
    e.location,        -- 備品情報．保管場所
    e.is_active,        -- 備品情報．有効フラグ
    lr.due_date          -- 貸出申請情報．返却予定日（貸出中の申請がない場合はNULL）
  FROM equipment e
  LEFT JOIN loan_request lr
    ON lr.equipment_id = e.id
    AND lr.status = 'lending'    -- 検索条件．貸出申請情報．状態
  WHERE
    (:category IS NULL OR e.category = :category)    -- 検索条件．分類
    AND (
      :keyword IS NULL
      OR e.name LIKE '%' || :keyword || '%'
      OR e.description LIKE '%' || :keyword || '%'
    )                                                  -- 検索条件．キーワード
    AND (:is_active IS NULL OR e.is_active = :is_active)  -- 検索条件．有効フラグ
  ORDER BY
    e.asset_number ASC;
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 取得内容 | 内部ID | - | - | - |
  | 取得内容 | 資産番号 | - | - | - |
  | 取得内容 | 備品名 | - | - | - |
  | 取得内容 | 分類 | - | - | - |
  | 取得内容 | 説明 | - | - | - |
  | 取得内容 | 保管場所 | - | - | - |
  | 取得内容 | 有効フラグ | - | - | - |
  | 取得内容 | 返却予定日 | - | - | 貸出中の申請がない場合は`null` |
  | 検索条件 | 分類 | - | 入力値．分類検索条件 | `null`の場合は絞り込みなし |
  | 検索条件 | キーワード | - | 入力値．キーワード検索条件 | `null`の場合は絞り込みなし |
  | 検索条件 | 有効フラグ | - | 入力値．有効フラグ検索条件 | `null`の場合は絞り込みなし |

- (2) 取得結果の各行について、返却予定日の有無から貸出状況を判定する

  - ① 返却予定日が設定されている場合、貸出状況に`lending`を設定する
  - ② 返却予定日が設定されていない場合、貸出状況に`available`を設定する
