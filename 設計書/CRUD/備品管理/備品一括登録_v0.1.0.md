### 処理概要

#### 【目的】
- 複数件の備品を一括で新規登録する。

#### 【処理概略】
- 入力値の登録対象リストの各要素について、資産番号・備品名・分類・説明・保管場所を設定した備品レコードを新規作成し、DBに追加する。

## ○処理詳細

### 1. 備品一括登録

- (1) 入力値．登録対象リストの要素ごとに、EQUIPMENTテーブルに新規レコードを追加する。

  ```sql
  INSERT INTO equipment (
    asset_number,    -- 備品情報．資産番号
    name,            -- 備品情報．備品名
    category,        -- 備品情報．分類
    description,     -- 備品情報．説明
    location,        -- 備品情報．保管場所
    is_active,       -- 備品情報．有効フラグ
    created_at        -- 備品情報．作成日時
  ) VALUES (
    :asset_number, :name, :category, :description, :location, :is_active, :created_at
  );
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 登録内容 | 資産番号 | ○ | 入力値．登録対象リスト．資産番号 | - |
  | 登録内容 | 備品名 | ○ | 入力値．登録対象リスト．備品名 | - |
  | 登録内容 | 分類 | ○ | 入力値．登録対象リスト．分類 | - |
  | 登録内容 | 説明 | - | 入力値．登録対象リスト．説明（未指定時は`null`） | - |
  | 登録内容 | 保管場所 | - | 入力値．登録対象リスト．保管場所（未指定時は`null`） | - |
  | 登録内容 | 有効フラグ | ○ | `true` | - |
  | 登録内容 | 作成日時 | ○ | 現在時刻 | - |

- (2) 登録した件数を取得する
