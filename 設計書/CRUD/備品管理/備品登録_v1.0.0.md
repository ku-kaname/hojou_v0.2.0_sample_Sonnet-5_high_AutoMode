## ○処理詳細

### 1. 備品登録

- (1) EQUIPMENTテーブルに新規レコードを追加する。

  ```sql
  INSERT INTO equipment (
    asset_number,    -- 備品情報．資産番号
    name,            -- 備品情報．備品名
    category,        -- 備品情報．分類
    description,     -- 備品情報．説明
    location,        -- 備品情報．保管場所
    is_active,       -- 備品情報．有効フラグ
    created_at        -- 備品情報．作成日時
  ) VALUES (
    :asset_number, :name, :category, :description, :location, :is_active, :created_at
  );
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 登録内容 | 資産番号 | ○ | 入力値．資産番号 | - |
  | 登録内容 | 備品名 | ○ | 入力値．備品名 | - |
  | 登録内容 | 分類 | ○ | 入力値．分類 | - |
  | 登録内容 | 説明 | - | 入力値．説明（未指定時は`null`） | - |
  | 登録内容 | 保管場所 | - | 入力値．保管場所（未指定時は`null`） | - |
  | 登録内容 | 有効フラグ | ○ | `true` | - |
  | 登録内容 | 作成日時 | ○ | 現在時刻 | - |
