## ○処理詳細

### 1. 備品取得

- (1) EQUIPMENTテーブルから取得する。

  ```sql
  SELECT
    id,                -- 備品情報．内部ID
    asset_number,      -- 備品情報．資産番号
    name,              -- 備品情報．備品名
    category,          -- 備品情報．分類
    description,       -- 備品情報．説明
    location,          -- 備品情報．保管場所
    is_active,         -- 備品情報．有効フラグ
    created_at,        -- 備品情報．作成日時
    updated_at         -- 備品情報．更新日時
  FROM equipment
  WHERE
    asset_number = :asset_number;  -- 入力値．資産番号
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 取得内容 | 内部ID | - | - | - |
  | 取得内容 | 資産番号 | - | - | - |
  | 取得内容 | 備品名 | - | - | - |
  | 取得内容 | 分類 | - | - | - |
  | 取得内容 | 説明 | - | - | - |
  | 取得内容 | 保管場所 | - | - | - |
  | 取得内容 | 有効フラグ | - | - | - |
  | 取得内容 | 作成日時 | - | - | - |
  | 取得内容 | 更新日時 | - | - | - |
  | 検索条件 | 資産番号 | ○ | 入力値．資産番号 | - |
