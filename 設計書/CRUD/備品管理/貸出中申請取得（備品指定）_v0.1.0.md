#### 【目的】
- 指定した備品について、現在貸出中の申請を1件取得する。

## ○処理詳細

### 1. 貸出中申請取得

- (1) LOAN_REQUESTテーブルから取得する。

  ```sql
  SELECT
    id,          -- 貸出申請情報．内部ID
    due_date     -- 貸出申請情報．返却予定日
  FROM loan_request
  WHERE
    equipment_id = :equipment_internal_id  -- 入力値．備品内部ID
    AND status = 'lending';                 -- 貸出申請情報．状態
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 取得内容 | 内部ID | - | - | - |
  | 取得内容 | 返却予定日 | - | - | - |
  | 検索条件 | 備品内部ID | ○ | 入力値．備品内部ID | - |
  | 検索条件 | 状態 | ○ | `lending` | - |
