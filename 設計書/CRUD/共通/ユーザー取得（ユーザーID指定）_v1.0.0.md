## ○処理詳細

### 1. ユーザー取得

- (1) USERテーブルから取得する。

  ```sql
  SELECT
    id,                    -- ユーザー情報．内部ID
    user_id,                -- ユーザー情報．ユーザーID
    name,                   -- ユーザー情報．氏名
    department,             -- ユーザー情報．所属
    hashed_password,        -- ユーザー情報．パスワードハッシュ
    role,                   -- ユーザー情報．ロール
    is_active,              -- ユーザー情報．有効フラグ
    must_change_password,   -- ユーザー情報．初回パスワード変更要否フラグ
    token_version,          -- ユーザー情報．トークン世代
    failed_login_count,     -- ユーザー情報．連続認証失敗回数
    locked_until            -- ユーザー情報．ロック解除日時
  FROM user
  WHERE
    user_id = :user_id;  -- 入力値．ユーザーID
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 取得内容 | 内部ID | - | - | - |
  | 取得内容 | ユーザーID | - | - | - |
  | 取得内容 | 氏名 | - | - | - |
  | 取得内容 | 所属 | - | - | - |
  | 取得内容 | パスワードハッシュ | - | - | - |
  | 取得内容 | ロール | - | - | - |
  | 取得内容 | 有効フラグ | - | - | - |
  | 取得内容 | 初回パスワード変更要否フラグ | - | - | - |
  | 取得内容 | トークン世代 | - | - | - |
  | 取得内容 | 連続認証失敗回数 | - | - | - |
  | 取得内容 | ロック解除日時 | - | - | - |
  | 検索条件 | ユーザーID | ○ | 入力値．ユーザーID | - |
