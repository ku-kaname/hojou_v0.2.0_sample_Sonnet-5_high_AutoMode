## ○処理詳細

### 1. ユーザー登録

- (1) USERテーブルに新規レコードを追加する。

  ```sql
  INSERT INTO user (
    user_id,                 -- ユーザー情報．ユーザーID
    name,                    -- ユーザー情報．氏名
    department,              -- ユーザー情報．所属
    hashed_password,         -- ユーザー情報．パスワードハッシュ
    role,                    -- ユーザー情報．ロール
    is_active,               -- ユーザー情報．有効フラグ
    must_change_password,    -- ユーザー情報．初回パスワード変更要否フラグ
    failed_login_count,      -- ユーザー情報．連続認証失敗回数
    locked_until,            -- ユーザー情報．ロック解除日時
    token_version,           -- ユーザー情報．トークン世代
    created_at                -- ユーザー情報．作成日時
  ) VALUES (
    :user_id, :name, :department, :hashed_password, :role,
    :is_active, :must_change_password, :failed_login_count, :locked_until, :token_version, :created_at
  );
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 登録内容 | ユーザーID | ○ | 入力値．ユーザーID | - |
  | 登録内容 | 氏名 | ○ | 入力値．氏名 | - |
  | 登録内容 | 所属 | - | 入力値．所属（未指定時は`null`） | - |
  | 登録内容 | パスワードハッシュ | ○ | 入力値．パスワードハッシュ | - |
  | 登録内容 | ロール | ○ | 入力値．ロール | - |
  | 登録内容 | 有効フラグ | ○ | `true` | - |
  | 登録内容 | 初回パスワード変更要否フラグ | ○ | `true` | - |
  | 登録内容 | 連続認証失敗回数 | ○ | `0` | - |
  | 登録内容 | ロック解除日時 | - | `null` | - |
  | 登録内容 | トークン世代 | ○ | `0` | - |
  | 登録内容 | 作成日時 | ○ | 現在時刻 | - |
