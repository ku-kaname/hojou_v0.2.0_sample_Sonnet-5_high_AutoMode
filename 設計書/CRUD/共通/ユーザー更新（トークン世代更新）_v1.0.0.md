### 処理概要

#### 【目的】
- ユーザーのトークン世代を1つ進め、それ以前に発行された全トークンを失効させる。

#### 【処理概略】
- 入力値の内部IDに一致するユーザーのトークン世代を1加算した値に更新する。
- 認証・認可（auth）「ログアウト」から呼び出される。

## ○処理詳細

### 1. ユーザー更新

- (1) USERテーブルを更新する。

  ```sql
  UPDATE user
  SET
    token_version = token_version + 1,  -- ユーザー情報．トークン世代
    updated_at = :updated_at            -- ユーザー情報．更新日時
  WHERE
    id = :id;  -- ユーザー情報．内部ID
  ```
