| メソッド物理名 | create_notification |

### 処理概要

#### 【目的】
- アプリ内通知を1件登録する。

#### 【処理概略】
- 宛先ユーザーID・種別・関連申請IDを設定した通知レコードを新規作成し、DBに追加する。
- 承認・却下・取消・新規申請・返却期限（前日・期限超過中）の各オーケストレーション処理から呼び出される（呼び出し元は各機能群の処理記述書で定める）。

## ○処理詳細

### 1. 通知登録

- (1) NOTIFICATIONテーブルに新規レコードを追加する。

  ```sql
  INSERT INTO notification (
    recipient_user_id,   -- 通知情報．宛先ユーザーID
    notification_type,   -- 通知情報．種別
    loan_request_id,      -- 通知情報．関連申請ID
    is_read,              -- 通知情報．既読フラグ
    created_at             -- 通知情報．作成日時
  ) VALUES (
    :recipient_user_id, :notification_type, :loan_request_id, :is_read, :created_at
  );
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 登録内容 | 宛先ユーザーID | ○ | 入力値．宛先ユーザーID | - |
  | 登録内容 | 種別 | ○ | 入力値．種別 | - |
  | 登録内容 | 関連申請ID | ○ | 入力値．関連申請ID | - |
  | 登録内容 | 既読フラグ | ○ | `false` | - |
  | 登録内容 | 作成日時 | ○ | 現在時刻 | - |
