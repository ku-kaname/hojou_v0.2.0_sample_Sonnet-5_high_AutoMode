### 処理概要

#### 【目的】
- 指定した宛先ユーザー宛の通知を一覧取得する。

#### 【処理概略】
- 入力値の宛先ユーザーIDに一致する通知情報を、作成日時の降順（新しい順）でNOTIFICATIONテーブルから取得する。

## ○処理詳細

### 1. 通知一覧取得

- (1) NOTIFICATIONテーブルから取得する。

  ```sql
  SELECT
    id,                  -- 通知情報．内部ID
    recipient_user_id,   -- 通知情報．宛先ユーザーID
    notification_type,   -- 通知情報．種別
    loan_request_id,      -- 通知情報．関連申請ID
    is_read,              -- 通知情報．既読フラグ
    created_at             -- 通知情報．作成日時
  FROM notification
  WHERE
    recipient_user_id = :recipient_user_id   -- 通知情報．宛先ユーザーID
  ORDER BY
    created_at DESC;
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 取得内容 | 内部ID | - | - | - |
  | 取得内容 | 宛先ユーザーID | - | - | - |
  | 取得内容 | 種別 | - | - | - |
  | 取得内容 | 関連申請ID | - | - | - |
  | 取得内容 | 既読フラグ | - | - | - |
  | 取得内容 | 作成日時 | - | - | - |
  | 検索条件 | 宛先ユーザーID | ○ | 入力値．宛先ユーザーID | - |
