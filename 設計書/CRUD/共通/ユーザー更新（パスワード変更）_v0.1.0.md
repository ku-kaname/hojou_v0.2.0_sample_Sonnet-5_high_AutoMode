### 処理概要

#### 【目的】
- ユーザーのパスワードハッシュを更新し、初回パスワード変更要否フラグを解除し、トークン世代を進める。

#### 【処理概略】
- 入力値の内部IDに一致するユーザーのパスワードハッシュを更新し、初回パスワード変更要否フラグを`false`に、トークン世代を1加算した値に更新する。
- 認証・認可（auth）「パスワード変更」から呼び出される。

## ○処理詳細

### 1. ユーザー更新

- (1) USERテーブルを更新する。

  ```sql
  UPDATE user
  SET
    hashed_password = :hashed_password,          -- ユーザー情報．パスワードハッシュ
    must_change_password = false,                -- ユーザー情報．初回パスワード変更要否フラグ
    token_version = token_version + 1,           -- ユーザー情報．トークン世代
    updated_at = :updated_at                     -- ユーザー情報．更新日時
  WHERE
    id = :id;  -- ユーザー情報．内部ID
  ```

  | 区分 | 項目名 | 必須 | 設定値・設定元 | 備考 |
  |---|---|:---:|---|---|
  | 更新内容 | パスワードハッシュ | ○ | 入力値．パスワードハッシュ | - |
  | 更新内容 | 初回パスワード変更要否フラグ | ○ | `false` | - |
  | 更新内容 | トークン世代 | ○ | 更新前のトークン世代+1 | 変更前に発行済みのトークンを失効させる |
  | 更新内容 | 更新日時 | ○ | 現在時刻 | - |
  | 検索条件 | 内部ID | ○ | 入力値．内部ID | - |
