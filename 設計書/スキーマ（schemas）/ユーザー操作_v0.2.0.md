## ユーザー作成リクエスト
### クラス
|論理名|物理名|継承元|
|---|---|---|
| ユーザー作成リクエスト | UserCreateRequest | BaseModel |

### 項目
|論理名|物理名|型|必須|最小値|最大値|最小桁|最大桁|備考|
|---|---|---|---|---|---|---|---|---|
| ユーザーID | user_id | str | ○ | - | - | 3 | 32 | 半角英数字と`_`・`-` |
| 氏名 | name | str | ○ | - | - | 1 | 50 | - |
| 所属 | department | str \| None | - | - | - | 0 | 50 | 空文字許容。未指定時は`null` |
| 初期パスワード | password | str | ○ | - | - | 8 | 255 | - |
| ロール | role | str | ○ | - | - | - | - | `general`（一般）／`admin`（管理者） |
