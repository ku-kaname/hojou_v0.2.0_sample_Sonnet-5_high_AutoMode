| メソッド物理名 | export_loan_request_history_endpoint |

### 処理概要

#### 【目的】
- 管理者が、期間・備品・借用者で絞り込んだ貸出履歴をCSVファイルとして出力する。

#### 【処理概略】
- 「貸出履歴検索・取得」と同一の検索条件・取得処理で貸出履歴を取得する。
- 取得結果をCSV形式に変換する。数式注入対策として、文字列項目の先頭が`=`・`+`・`-`・`@`の場合は先頭に`'`を付与する。
- UTF-8（BOM付き）でエンコードしたCSVファイルをダウンロード応答として返却する。

## ○処理詳細

### 1. 貸出履歴一覧を取得する

- (1) 以下メソッドを呼び出す。

  **呼出先**

  | 項目 | 論理名 | 物理名 |
  |---|---|---|
  | クラス | - | - |
  | メソッド | 貸出履歴検索 | get_loan_request_history |

  **引数**

  | 引数 | 型 | 必須 | 設定値 | 備考 |
  |---|---|:---:|---|---|
  | データベース | `Session` | ○ | 入力値．データベース | - |
  | 開始日検索条件（自） | `date \| None` | - | 入力値．クエリパラメータ．開始日（自） | - |
  | 開始日検索条件（至） | `date \| None` | - | 入力値．クエリパラメータ．開始日（至） | - |
  | 資産番号検索条件 | `str \| None` | - | 入力値．クエリパラメータ．資産番号 | - |
  | 借用者ユーザーID検索条件 | `str \| None` | - | 入力値．クエリパラメータ．借用者ユーザーID | - |

### 2. 状態を日本語ラベルに変換する

- (1) 貸出履歴一覧を取得結果の各要素について、状態を以下の対応で日本語ラベルに変換する

  | 状態（物理値） | 日本語ラベル |
  |---|---|
  | `pending` | 申請中 |
  | `approved` | 承認済み |
  | `lending` | 貸出中 |
  | `returned` | 返却済み |
  | `rejected` | 却下 |
  | `cancelled` | 取消 |

### 3. CSVデータを生成する

- (1) 以下の列順でヘッダー行を設定する

  資産番号, 備品名, 申請者氏名, 開始日, 返却予定日, 用途, 状態, 却下・取消理由, 申請日時, 承認・却下日時, 承認・却下者氏名, 貸出日時, 貸出処理者氏名, 返却日時, 返却処理者氏名, 状態メモ, 取消日時, 取消処理者氏名

- (2) 貸出履歴一覧を取得結果の各要素について、ヘッダー行の列順に対応するデータ行を設定する

  | 列 | 設定値 |
  |---|---|
  | 資産番号 | 貸出履歴一覧を取得結果の要素．資産番号 |
  | 備品名 | 貸出履歴一覧を取得結果の要素．備品名 |
  | 申請者氏名 | 貸出履歴一覧を取得結果の要素．申請者氏名 |
  | 開始日 | 貸出履歴一覧を取得結果の要素．開始日 |
  | 返却予定日 | 貸出履歴一覧を取得結果の要素．返却予定日 |
  | 用途 | 貸出履歴一覧を取得結果の要素．用途 |
  | 状態 | 2．変換後の日本語ラベル |
  | 却下・取消理由 | 貸出履歴一覧を取得結果の要素．却下・取消理由（未設定時は空欄） |
  | 申請日時 | 貸出履歴一覧を取得結果の要素．申請日時 |
  | 承認・却下日時 | 貸出履歴一覧を取得結果の要素．承認・却下日時（未到達時は空欄） |
  | 承認・却下者氏名 | 貸出履歴一覧を取得結果の要素．承認・却下者氏名（未到達時は空欄） |
  | 貸出日時 | 貸出履歴一覧を取得結果の要素．貸出日時（未到達時は空欄） |
  | 貸出処理者氏名 | 貸出履歴一覧を取得結果の要素．貸出処理者氏名（未到達時は空欄） |
  | 返却日時 | 貸出履歴一覧を取得結果の要素．返却日時（未到達時は空欄） |
  | 返却処理者氏名 | 貸出履歴一覧を取得結果の要素．返却処理者氏名（未到達時は空欄） |
  | 状態メモ | 貸出履歴一覧を取得結果の要素．状態メモ（未設定時は空欄） |
  | 取消日時 | 貸出履歴一覧を取得結果の要素．取消日時（未到達時は空欄） |
  | 取消処理者氏名 | 貸出履歴一覧を取得結果の要素．取消処理者氏名（未到達時は空欄） |

- (3) 数式注入対策として、以下の文字列項目について、値の先頭文字が`=`・`+`・`-`・`@`のいずれかの場合、値の先頭に`'`（シングルクォート）を付与する

  資産番号, 備品名, 申請者氏名, 用途, 却下・取消理由, 承認・却下者氏名, 貸出処理者氏名, 返却処理者氏名, 状態メモ, 取消処理者氏名

### 4. CSVファイルを返却する

- (1) 3．で生成したCSVデータを、UTF-8（BOM付き）でエンコードしたファイルとして返却する

  | 項目 | 設定値 | 備考 |
  |---|---|---|
  | Content-Type | `text/csv; charset=utf-8` | - |
  | Content-Disposition | `attachment; filename="loan_history.csv"` | ファイル名は固定（半角英数字のみ） |
